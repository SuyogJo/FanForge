# Manual MetaMask Setup for Chiliz Spicy Testnet

If you're getting a "Chain ID mismatch" error, you can manually add the network to MetaMask:

## Steps to Add Chiliz Spicy Testnet Manually:

1. **Open MetaMask** and click the network dropdown (top of the extension)

2. **Click "Add Network"** or "Add a network manually"

3. **Enter the following details:**
   - **Network Name:** `Chiliz Spicy Testnet`
   - **RPC URL:** `https://spicy-rpc.chiliz.com`
   - **Chain ID:** `88882`
   - **Currency Symbol:** `CHZ`
   - **Block Explorer URL:** `https://testnet.chiliscan.com`

4. **Click "Save"**

5. **Switch to the network** and try connecting again

## Alternative: Use Chainlist

You can also use [Chainlist.org](https://chainlist.org) to add the network:
1. Go to https://chainlist.org
2. Search for "Chiliz Spicy"
3. Click "Connect Wallet"
4. Approve the network addition

## Verify Network is Added Correctly

After adding, verify:
- Network name shows "Chiliz Spicy Testnet"
- Chain ID is 88882
- You can see your CHZ balance (if you have testnet tokens)
